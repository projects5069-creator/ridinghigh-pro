# ✅ **Google Apps Script, מקושר לגיליון, trigger כל 5 דקות**

**מדוע דווקא הוא:** הוא **התשתית היחידה שלנו שאינה GitHub ואינה המק**. הוא הריץ,
היום, בזמן שכל השאר היה תקוע. הוא שולח מייל בלי שום credential, קורא GitHub API בלי
token, ועולה $0.

**למה כל אחת נדחתה — משפט אחד:**
* **ב · launchd** — `womp 0` ו-`sleep 1`: המק ישן ואי אפשר להעיר אותו מהרשת; ואותו מנגנון plist הוא זה שירה 9 לילות אחרי שתועד כמנוטרל.
* **ג · cron-job.org** — אינו בודק תוכן תשובה, וה-API החזיר `HTTP 200` עם 374 בתור; היום הוא היה שותק.
* **ד · workflow נפרד** — `runners=0`, כולם `ubuntu-latest`: אותו pool, היה מצטרף לתור במקום לזעוק עליו.
* **ה · שירות קיים** — אין. ה-webhook היחיד הוא פריסת ה-dashboard.

### תוכנית מימוש

**איפה יושב:** סקריפט container-bound על אחד מגיליונות המערכת. ⚠️ **המלצה: על גיליון
`RH-Summaries` ולא על גיליון חודשי** — הגיליונות החודשיים מסתובבים ב-1 לחודש
(`monthly_rotation`), וסקריפט מקושר-לגיליון-חודשי ימות ברוטציה הבאה.

**מה נבנה — קובץ אחד, ~90–120 שורות JavaScript:**

| חלק | ~שורות | תפקיד |
|---|---|---|
| `UrlFetchApp` → `runs?status=queued&per_page=1` | ~10 | אות 2: `total_count` |
| `UrlFetchApp` → `runs?status=completed&per_page=50` | ~15 | אות 1b: ספירת `updated_at` בחלונות 15/75 דק׳ |
| חלון-זמן 14:45–19:45Z | ~5 | מונע שווא בנעילה ובסופ"ש |
| כלל הכרעה (שני האותות) | ~20 | הספים שנמדדו למעלה |
| דה-דופ (`PropertiesService`) | ~15 | מייל אחד לאירוע, לא 6 |
| `MailApp.sendEmail` | ~15 | ההתראה |
| לוג לטאב ייעודי | ~15 | ראיה שהשומר עצמו חי |

**מה נדרש ממך ידנית — ארבעה צעדים, אין קוד שאני יכול לדחוף:**
1. לפתוח את הגיליון → `Extensions › Apps Script`.
2. להדביק את הקובץ (אכתוב אותו רק אחרי GO).
3. `Triggers › Add trigger` → time-driven → every 5 minutes.
4. לאשר את בקשת ההרשאות בפעם הראשונה (`UrlFetchApp` + `MailApp` + הגיליון).

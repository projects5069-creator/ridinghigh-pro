## 3. הערכת החיסכון — ⚠️ הערכה, לא מדידה

| תרחיש | קריאות API לריצה | ליום מסחר (~160 ריצות אחרי ה-batch) |
|---|---|---|
| היום | ~61 READ + ~61 WRITE = **~122** | ~19,520 |
| **TASK-218 בלבד** (קאש handle) | **1** READ + ~61 WRITE = **~62** | ~9,920 |
| **218 + צבירה** | 1 READ + **1** WRITE = **2** | ~320 |

**⚠️ כל המספרים האלה הערכות.** המדידה האמיתית תהיה בייצור.

### משך הריצה — השאלה שמכריעה את גורל ה-`concurrency`
```
נמדד 5/8:   203s  =  ~40s תקורה + 106s SMA20 + 45s לולאת הסיגנלים + ~12s שאר
נחת כבר:    ה-batch ל-SMA20 (fcdb0aa, ב-main)
```
```
203 − 106 (SMA20)  = 97s
 97 −  45 (סנטינל) = 52s      ← מתחת ל-60
```
⚠️ **אבל שני המספרים שמופחתים הם הערכות עליונות:**
- **106s לא אומתו בייצור.** מדידת ההיתכנות נתנה 9.05s סדרתי מקומית מול 106s ב-Actions —
  **פער פי 12 שלא הוסבר**. אם רק חלקו נובע מ-throttling, החיסכון קטן יותר.
- **45s הן כל הלולאה**, לא רק כתיבות ה-Sentinel. חלקן הוא הערכת-סיגנל עצמה.

**התשובה הכנה: ייתכן שמתחת ל-60, אבל אי-אפשר לקבוע זאת מהמספרים שיש.**
**המדידה בייצור אחרי שה-SMA20 batch רץ יום שלם היא מה שיכריע** — והיא זמינה
כבר היום אחרי הנעילה.
